## 一、物理模型与问题定义

### 背景

吹膜机上旋（人字架）做**往复旋转**：从 0° 转到 θ_max，再从 θ_max 转回 0°，
如此循环。**θ_max（最大旋转角度）是本算法需要推断的核心参数**，满足：

```
180° < θ_max < 360°
```

### 测厚信号模型

测厚仪采集的是**压平后双层薄膜**的叠加厚度：

```
T(t) = f(θ(t)) + f(θ(t) + π)
```

其中 `f(·)` 是膜泡周向厚度分布函数（以 2π 为周期）。
由于正反对称抵消，**奇次谐波（k=1,3,5,…）在测厚信号中相消，只有偶次谐波可见**。
因此算法信号源为 k=2, 4 等偶次谐波分量。

### 角度映射（梯形速度曲线）

上旋并非匀速旋转，在端点附近存在加减速。采用**梯形速度曲线**建模：

```typescript
trapezoidalPosition(progress, accelRatio)
// progress ∈ [0, 1]: 行程进度
// accelRatio: 加速段占总时长的比例（默认 min(20000ms, duration×0.45) / duration）
```

## 三、当前算法架构（`upperRotation.ts`）

### 主入口

```typescript
export const estimateThetaMaxWithPhaseCorrection(
  tripSegments: TripSegment[],
  options?: { segments?, deltaRange? }
): number | null
```

### 三路策略（优先级从高到低）

```
1. 脉冲路径（最准确）
   条件：数据中存在 HorizontalPulse 字段，且覆盖率 ≥ 50%
   函数：estimateWithPulseExpansion()
   原理：脉冲值直接映射为扫描仪偏移角度 offsetDeg ∈ [-90°, +90°]

2. 扫描段展开法（回退，有间隙数据）
   条件：无脉冲，但数据中检测到扫描间隙（gap ≥ 5 处）
   函数：estimateWithScannerExpansion()
   原理：将扫描往返分组，奇偶组交替赋予 [-90°, +90°] 偏移

3. 原始 bin 方差法（最终回退）
   条件：无脉冲、无间隙
   函数：estimateOriginal()
   原理：梯形速度曲线映射时间 → 角度，bin 内方差最小化
```

### 搜索策略（三路共用）

```
粗搜索：1° 步长，范围 [min, max)（默认 [180, 359)）
精搜索：0.1° 步长，±2° 范围内
最终收敛：黄金分割搜索（精度 0.01°）
```

### 目标函数

- 粗/精搜索（三路共用）：`evaluateExpanded()` — bin 方差法（带梯形修正）
- **脉冲路径最终收敛（黄金分割）**：`evaluateSpectral()` — 偶次谐波相干功率法（k=2,4，已激活 ✅）
- 扫描段/原始路径最终收敛：`evaluateExpanded()` — bin 方差法（无脉冲时回退）

### 预处理：过滤不完整片段

```typescript
filterPartialSegments(segments)
// 以中位数时长的 80% 为阈值，剔除首尾不完整片段
// 若过滤后 < 2 段则回退使用全量
```

## 五、关键设计决策（历史记录）

### 决策 1：废弃 upperRotation.a.ts（谐波搜索法）

- **原因**：直接谐波拟合对数据量要求高，在稀疏片段上不稳定
- **替代**：bin 方差最小化 + 黄金分割搜索

### 决策 2：废弃 upperRotation.b.ts（单程黄金分割法）

- **原因**：仅用正向或反向单程，忽略了上旋往复特性，精度不足
- **替代**：多片段联合估计（filterPartialSegments + 多段 evaluateExpanded）

### 决策 3：脉冲范围仅用在界点（`!isNaN(m.y)`）计算

- **原因**：出界点（y=NaN）对应膜外缓冲区，其脉冲位置不代表实际膜宽，
  会导致 pulseMin/pulseMax 不对称，引入系统偏差
- **实现**：`estimateWithPulseExpansion` 中计算 pulseRange 时过滤 NaN 点

### 决策 4：梯形速度曲线（而非线性映射）

- **原因**：上旋在端点附近加减速，线性映射会导致端部角度偏差
- **参数**：`accelRatio = min(20000ms, duration * 0.45) / duration`

### 决策 5：保留 `evaluateSpectral` 作为脉冲路径的最终收敛器

- **原因**：谱分析无 bin 离散化误差，Fourier 变换是最优线性滤波器，
  在粗/精搜索已缩小到 ±1° 邻域后，切换至谱分析做最终黄金分割收敛精度更高
- **状态**：✅ 已激活（2026-03-16）
- **实现位置**：`estimateWithPulseExpansion()` 末尾的 `goldenSectionSearch`

### 决策 6：非脉冲路径继续使用 `evaluateExpanded` 收敛

- **原因**：`evaluateSpectral` 依赖 `offsetDeg` 字段，扫描段展开法的 `offsetDeg`
  是假设奇偶分组方向分配的近似值，精度低于脉冲路径；谱分析在此情况下优势不明显，
  故扫描段/原始路径保留 bin 方差法做最终收敛
- **结论**：仅在数据质量最高的脉冲路径中启用谱分析精化

## 十、关于测厚仪出界数据的处理原则

1. 出界点（`y = NaN`）**必须**在参与角度映射前过滤，否则会污染 bin 统计
2. 脉冲路径中，出界点的 `pulse` 值不参与 `pulseMin/pulseMax` 计算
3. 可选择全部剔除或使用平滑插值，具体取决于数据密度；
   当前实现选择剔除（`filter(!isNaN(p.y))`）

## 十一、ProbeValue 在样本数据与算法/模拟器中的差异 ⚠️

### 结论

| 场景 | ProbeValue 含义 | 出界时的值 | 信号方向 |
|------|----------------|-----------|---------|
| **样本数据文件**（`data/01-05`） | **光通量**（原始采集，无量纲） | **极大值**（无膜遮挡，光全透） | 膜越厚 → 值越**低**（负相关） |
| **算法接口设计**（生产代码） | **双层膜厚（μm）** | — | 膜越厚 → 值越**高**（正相关） |
| **仿真器**（Simulation） | **双层膜厚（μm）** | **0**（或 null） | 膜越厚 → 值越**高**（正相关） |

> 算法和模拟器的接口设计统一为 **μm**。样本数据文件是直接从设备采集的原始光通量值，
> 是历史数据的特殊情况，并非生产代码路径的设计。

### 样本数据的出界过滤机制

由于样本数据的光通量在出界时极大，`buildTripSegment` 通过 `detectBimodalThreshold`
检测两峰之间的谷底阈值，将出界点标记为 `NaN`。这与模拟器的 `> 0` 过滤是两条不同路径，
但**对 θ_max 估算算法均正确兼容**（算法只依赖相对变化，对绝对值和信号方向不敏感）。

### 对各算法的影响

| 算法 | 样本数据是否受影响 | 原因 |
|------|-----------|------|
| `estimateThetaMaxWithPhaseCorrection` | **不受影响** | 只依赖相对变化方差，对信号方向和绝对尺度不敏感 |
| `evaluateSpectral`（谐波功率） | **不受影响** | 相干功率对信号方向不敏感（取平方） |
| 厚度反推 / 风量调整控制器 | **⚠️ 样本数据不可直接用于此类算法** | 需要实际 μm 值；若用样本数据验证，必须先做光通量 → 厚度转换 |

### 光通量 → 厚度转换（仅样本数据验证时需要）

`buildTripSegment` 提供了可选的 `probeValueConverter` 参数，
当需要用样本数据验证依赖 μm 值的下游算法时，可传入标定转换函数：

```typescript
// 使用样本数据验证需要实际厚度的算法时
const { next } = buildTripSegment({
  probeValueConverter: (raw) => gain * raw + offset
  // 或反比关系：(raw) => k / raw
})
```

生产代码路径（OPC UA 实时数据 / 仿真器）无需传此参数，
因为生产数据在进入算法前已是 μm。

> 注意：标定公式的具体形式（线性 / 反比 / 分段线性）需结合实际设备数据确定，
> 当前代码未内置具体换算公式。
