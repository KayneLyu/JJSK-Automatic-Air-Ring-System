### 算法优化的阶段性

```
阶段 1：架构级修复（D-010, D-011）
  问题：根本性的错误决策（如错误回退到 180°）
  修复：添加约束和门控
  效果：可能带来 10-100° 的巨大改善

阶段 2：参数精度优化（当前所在）
  问题：线性近似不适用（如固定加速度比、线性 offset 映射）
  修复：非线性拟合、自适应参数、加权融合
  效果：通常带来 ±5-15° 的改善

阶段 3：数据级改进（若阶段 2 仍不足）
  问题：源头数据质量（采集噪声、缺失值）
  修复：更好的传感器、采样频率提升
  效果：取决于硬件改进
```
