# Plan: 上旋影子统计速度 × 生产角度覆盖矩阵

1. 在工况统计模块中增加二维交叉单元与矩阵类型，复用现有局部接受率、差值分布和候选拒绝原因统计语义。
2. 按显式速度边界、生产角度边界和单元最少样本数生成完整矩阵，保留空单元并输出组合覆盖缺口。
3. 将矩阵接入影子批量统计；仅用于诊断，不改变批次接受、生产选择或设备控制路径。
4. 增加 3 × 3 组合覆盖、充分/不足/空单元、局部拒绝原因及非法阈值测试。
5. 运行格式化、相关单元测试、AirRingServer typecheck 和 diff 检查，并更新任务进度、决策与长期上下文。

## 验收标准

- 每个速度 × 生产角度组合都有确定单元，最后一行/列包含右边界。
- 空单元接受率为 `null`，不足单元具有明确缺口，充分单元保留三路径局部统计。
- 二维覆盖缺口不自动拒绝无标签影子批次，生产选择仍固定为原生产路径。
- 相关测试通过；typecheck 不新增与本轮变更相关的诊断。
