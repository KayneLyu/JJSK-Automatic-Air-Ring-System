4. 为 utility worker 的历史最大角度 IPC 启用该模式，并保留当前键集分页、线性归并和分层超时优化。
5. 执行主进程类型检查、类型感知 lint、完整 Vite 构建及产物检查。

8. 使用现场 `jjsk.db` 只读验证表数据、边界区间和完整 Worker 回放；确认真实数据可生成有效角度。

## 验收标准

- 历史最大角度不依赖牵引速度或突变窗口标定。
- 两个完整且有有效厚度测点的上旋行程会触发角度 Worker。
- 行程不足、信号无变化、Worker 超时或异常时返回具体错误，不再返回“成功但无 maxAngle”。
- TypeScript 检查与完整构建通过，未新增 lint 错误。
