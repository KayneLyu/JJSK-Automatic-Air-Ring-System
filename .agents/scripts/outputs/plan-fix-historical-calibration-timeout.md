# Plan: 修复历史上旋角度标定 120 秒超时

1. 将历史角度窗口从“最近最多三个行程到最新厚度”收紧为恰好最近两个完整行程；方向变化回退同样使用最后三个边界。
2. 将历史回放 Worker 的厚度查询从 `OFFSET` 分页改为 `(timestamp, id)` 游标分页，消除百万级数据的深分页退化。
3. 移除厚度与旋转事件对象的全量合并排序，改为对两个已排序数组做线性归并并直接回放。
4. 调整分层超时：角度 Worker 保持 120 秒，历史回放外层 180 秒，主进程 IPC 190 秒，为数据加载和进程通信保留边界。
5. 运行相关格式检查、AirRingSys 主进程 typecheck、类型感知 lint、完整 Vite 构建和产物检查。

## 验收标准

- 历史最大角度只读取生成两个完整行程所需的时间范围。
- 分页查询不再使用 `OFFSET`，相同时间戳通过 `id` 保证不重复、不遗漏。
- 回放顺序保持按时间戳递增，厚度与旋转同刻时维持厚度优先的旧排序语义。
- 外层超时严格大于内部角度 Worker 上限，不会在内部仍合法运行时提前终止。
- 主进程 typecheck 和 Vite 构建通过，不新增 lint 错误。
