# Plan: 上旋影子覆盖准备度摘要

1. 在补采目标模块中定义覆盖准备度摘要，区分 `notEvaluated`、`incomplete` 和 `satisfied`。
2. 对已评估目标直接汇总总目标、空目标、不足目标、一维目标和二维目标数量，并暴露最高优先级目标。
3. 将摘要接入影子批量统计；输入或配置在覆盖计算前失败时保持 `notEvaluated`，覆盖完成后独立于批次接受结果输出。
4. 增加未评估、覆盖不足、覆盖满足及批量接入测试，明确该摘要不表示算法准确度或生产切换资格。
5. 运行格式化、Stage 7+8 回归、类型感知 lint、AirRingServer typecheck 和 diff 检查。
6. 更新任务进度、决策与长期上下文。

## 验收标准

- 早期失败不会把空目标数组误报为覆盖已满足。
- 有目标时状态为 `incomplete`，各分类计数与目标清单一致，最高优先级目标等于清单首项。
- 无目标且已完成覆盖计算时状态为 `satisfied`。
- `coverageRequirementsSatisfied` 只表达显式分桶样本阈值，不影响影子批次接受和生产选择。
- 相关测试通过，且不新增本轮 TypeScript 或 lint 诊断。
