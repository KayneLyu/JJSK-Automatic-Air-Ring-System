# Plan: 上旋影子覆盖补采优先级清单

1. 新增独立纯函数模块，将一维工况缺口和速度 × 生产角度二维缺口转换为统一的可序列化补采目标。
2. 定义确定性排序：空覆盖优先、随后按记录缺口降序、同等条件下二维组合优先，最后按固定维度和桶索引排序。
3. 为每个目标输出连续优先级、目标类型、边界、现有记录数和需补记录数；不汇总重叠目标的记录缺口。
4. 将优先级清单接入影子批量统计，保持诊断用途，不改变批次接受或生产选择。
5. 增加顺序稳定性、空输入和批量接入测试；运行格式化、相关回归、类型感知 lint、AirRingServer typecheck 与 diff 检查。
6. 更新任务进度、决策和长期上下文。

## 验收标准

- 输入数组顺序改变不会改变目标顺序或优先级编号。
- 所有空覆盖目标排在少样本目标之前；同级按缺口、目标粒度和索引稳定排序。
- 清单保留一维与二维目标的完整边界，`additionalRecordsNeeded` 与原缺口一致。
- 不输出会重复计算交叉目标和边缘目标的“总需采集记录数”。
- 相关测试通过，且不新增本轮 TypeScript 或 lint 诊断。
