# Decisions: 推算膜泡原始厚度

## 2026-06-11 23:00 选择线性系统求解而非现有反推算法

**背景**: 现有 `thicknessReverseCalculation.ts` 使用旋转椭球体模型+泊松修正，仅对总厚度做几何修正，不分离 f(θ)+f(θ+π) 的两层。`upperRotation.a.ts` 中 `evaluateDeltaTheta()` 做了分箱但未完成反卷积。

**选择**: 构建 N 元线性系统，最小二乘求解 f(θ) 的离散值。

**理由**: 
- 仿真器正模型是精确的 T=f(α)+f(α+180°)，反模型应该是该方程的反解
- 线性系统在 α 全覆盖 360° 时有唯一解
- 上旋 6-8 分钟扫描一次 + 扫描仪 30s/行程，自然产生足够的 α 多样性
- 最小二乘求解是数值稳定且有正则化控制的成熟方法

**影响**: 
- 需要收集足够多的 (upperAngle, scannerPos, T) 三元组
- numBins 不宜过大（建议 ≤ 测量数/5）
- 需要标定 membraneWidth、processDeformationFactor

## 2026-06-11 23:30 选择正态方程而非 SVD 或 QR

**背景**: 求解最小二乘问题有多种方法（SVD、QR、正态方程）。

**选择**: 正态方程 (A^T·A + λI)·x = A^T·b + 高斯消元。

**理由**: 
- 矩阵规模小（N ≤ 360），SVD/QR 的计算开销不必要
- 正态方程对 Tikhonov 正则化有天然支持
- 高斯消元实现简单，不需要外部依赖
- 后续如果需要，可替换为 SVD 以提高条件数较差时的数值稳定性

**影响**: 若后续出现数值不稳定（bin 覆盖不均导致条件数高），再考虑切换到 SVD。
