# Plan: 上旋最大角度算法通用化

## 先写计划再动手

本计划按低风险基础设施、离线估计器、候选算法、影子运行和生产切换逐步推进。每个阶段只实施一项最小高收益动作，记录结果后再进入下一阶段。

## 阶段 0：任务隔离与基线定义

- [x] 建立标准 task 目录与四类文档。
- [x] 用户明确指定复用当前目录与 `main` 分支，并记录任务隔离例外。
- [x] 核对现有真实、模拟和现场数据的可用性及参考角度来源。
- [x] 定义开发集、调参集和冻结验收集；当前调参集与冻结验收集为空，等待独立现场真值。
- [x] 将模拟器验证改为分布驱动的随机生成测试，记录 seed 和生成参数以支持失败重放，不建立固定角度样本集。
- [x] 定义统一诊断结果格式及基线指标。

验收项：

- [x] 用户确认在当前目录实施；已检查开始时工作区仅包含本任务文档变更。
- [ ] 每份未来验收数据均有来源、工况和参考角度可信度说明；当前尚无合格冻结验收数据。
- [x] 已定义单次诊断字段和批量聚合指标；正反向差将在特征追踪接入后填充。

## 阶段 1：隔离现有定向策略

- [x] 让 `strategyProfile` 真正控制算法分支。
- [x] `generic` 路径跳过 H1、H2、C5 和 DS05-like 定向修正。
- [x] `datasetTuned2026Q1` 暂时保持当前行为，作为可回退对照。
- [x] 增加结构化诊断信息：基础角度、最终角度、规则触发、点数、loss、耗时和拒绝原因。
- [x] 通过显式影子对照API支持新旧路径成对计算；原生产入口及输出保持不变。

验收项：

- [x] generic 路径不执行 H1/H2/C5/DS05-like 定向规则。
- [x] 默认路径与显式旧 profile 结果保持一致。
- [x] 两条路径的差异可由 `strategyProfile`、基础/最终角度和 `triggeredRules` 可靠识别。

## 阶段 2：统一扫描剖面预处理

- [x] 按实际扫描位置重采样到固定长度，而不是按采样序号对齐。
- [x] 正反扫描统一为空间上的同一方向。
- [x] 过滤无效值并将已知位置范围外保留为缺失，支持按比例对称裁剪边缘。
- [x] 完成默认关闭的去均值、线性去趋势和缺失值感知轻度平滑。
- [x] 输出输入有效率、位置覆盖率、重采样缺失率、方向和结构化拒绝原因。

验收项：

- [x] 同一剖面正序和反序输入得到等价结果。
- [x] 不同采样密度重采样后线性特征位置稳定。
- [x] 覆盖不足或有效点不足的扫描被明确拒绝。
- [x] 预处理默认值不改变原始重采样结果，非法选项被明确拒绝。

## 阶段 3：实现可靠的特征追踪

- [x] 将当前互相关升级为独立的逐位移零均值归一化互相关（ZNCC）候选核心。
- [x] 根据双方有限值的实际重叠区单独归一化每个位移候选。
- [x] 实现互相关主峰的三点抛物线亚像素插值，边界或退化峰保持整数位移。
- [x] 根据设备允许角速度、扫描时间间隔和角度采样分辨率动态限制搜索窗口。
- [x] 输出主峰、次峰、峰值突出度、相关度、置信度证据向量和结构化拒绝原因。
- [ ] 检测周期性、多峰和 `180°` 等价造成的歧义；数值等价多峰与边界峰已拒绝，近等价峰已量化但待独立统计判据。

验收项：

- [ ] 模拟平移的中位角度误差达到约定目标。
- [x] 对随机噪声、幅值缩放、偏置和部分缺失的性质测试保持稳定，并输出随质量退化变化的证据。
- [ ] 模糊峰不会被静默接受。

## 阶段 4：估计角速度并稳健过滤

- [x] 使用真实扫描时间戳计算 `ωᵢ = Δθᵢ / Δtᵢ`。
- [x] 用换向信号提供期望方向并检查符号冲突，保留原始有符号速度和绝对速度。
- [ ] 排除换向附近、时间间隔异常和低置信度观测。
- [x] 使用无经验权重的中位数聚合匀速角速度。
- [ ] 使用 MAD 检测离群值和速度不稳定性；MAD、相对 MAD 与最大偏差已输出，拒绝判据待物理依据。
- [x] 由调用方显式定义每个完整行程所需的最少有效观测数。

验收项：

- [x] 分布性质测试确认单次极端错误不会显著改变最终匀速角速度。
- [ ] 正向和反向匀速角速度绝对值在设备容差内一致。
- [ ] 速度波动过大时拒绝该行程。

## 阶段 5：建立短端部加减速模型

- [ ] 换向点附近的数据不参与匀速特征估计。
- [ ] 第一版采用线性加减速端部补偿。
- [ ] 使用 `θmax = ωconst × (Thalf - (Tacc + Tdec) / 2)` 计算行程候选。
- [ ] 端部时间优先来自设备配置或实测，当前无法获取时使用有明确边界的机台配置。
- [ ] 对端部时间执行敏感性分析并输出其角度影响。

验收项：

- [ ] 不再通过历史标签误差选择 12000/13000/20000ms 等动作。
- [ ] 端部参数小幅变化不会造成不可接受的结果跳变。
- [ ] 所有端部时间和角度配置均有边界校验。

## 阶段 6：多行程最大角度候选

- [ ] 由去抖后的正反换向信号划分完整行程。
- [ ] 每个行程输出最大角度、匀速角速度、有效观测数、速度离散度和置信度。
- [ ] 至少联合一个正向和一个反向完整行程。
- [ ] 多行程使用中位数聚合并检测趋势漂移。
- [ ] 行程时长、换向顺序或方向异常时拒绝候选。

验收项：

- [ ] 正反向角度差和跨行程标准差满足设备验收要求。
- [ ] 不完整或异常行程不会进入最终估计。

## 阶段 7：通用目标函数局部精调

- [ ] 使用特征积分结果作为 `θfeature` 粗估。
- [ ] 根据粗估不确定度动态生成局部搜索半径。
- [ ] 仅保留通用 `evaluateExpanded`、局部搜索、黄金分割和边界保护。
- [ ] 比较特征估计和全局目标函数证据；明显冲突时拒绝标定。
- [ ] 输出最终角度、置信度、不确定度和证据来源。

验收项：

- [ ] 新路径不依赖 DS 编号、固定目标角度带或样本融合系数。
- [ ] 搜索不再跳入 180° 或 360° 附近的退化边界解。
- [ ] 双估计器冲突不会被任一分支无条件覆盖。

## 阶段 8：影子运行与独立验收

- [ ] 同时记录当前生产路径、generic 基线和新混合路径结果。
- [ ] 覆盖多机台、多速度、多角度、多膜宽和多配方数据。
- [ ] 至少收集 30 个完整标定窗口。
- [ ] 在冻结验收集上一次性计算最终指标。
- [ ] 检查最坏误差、严重错误和拒绝原因，而不只看平均误差。

建议初始验收目标，最终需结合设备精度确认：

- [ ] 最大角度中位绝对误差 `≤ 2°`。
- [ ] 95% 分位绝对误差 `≤ 5°`。
- [ ] 正反向估计差 `≤ 3°`。
- [ ] 同工况连续行程标准差 `≤ 2°`。
- [ ] 冻结验收集不存在大于 `10°` 的错误接受。
- [ ] 低置信度数据被拒绝，而不是输出伪精确结果。
- [ ] 单次估算保持小于 100ms。

## 阶段 9：生产切换与旧规则清理

- [ ] 通过现场影子验收后，将新通用路径切为默认。
- [ ] 旧 profile 保留一个明确版本周期作为回退。
- [ ] 稳定后删除 H1、H2、C5、DS05-like 和历史目标角度带。
- [ ] 删除不再需要的 `datasetTuned2026Q1` profile 和规则树。
- [ ] 将 DS01～DS05 保留为普通回归集。
- [ ] 更新项目长期 context、decisions 和算法说明。
- [ ] 完成任务验证、总结和归档。

## 每轮实施流程

1. 读取本任务 `context.md`、`plan.md`、`progress.md` 和 `decisions.md`。
2. 用 3～5 条总结当前状态。
3. 每轮只实施一个最小高收益动作。
4. 主动运行与风险相称的最小相关测试集，阶段验收运行对应测试矩阵。
5. 只追加更新 `progress.md`；重要取舍写入 `decisions.md`。
6. 若阶段验收失败，停止推进并记录原因，不通过新增样本定向规则掩盖问题。

## 预期产出

- 一个不依赖历史样本定向修正的 generic 基线。
- 一个带扫描标准化、ZNCC、亚像素峰值和置信度的特征追踪器。
- 一个基于换向行程、稳健角速度和短端部补偿的最大角度估计器。
- 一个“特征粗估 + 通用目标函数局部精调”的生产候选路径。
- 新旧路径影子对照与独立现场验收报告。
- 旧定向规则的安全退出和最终清理记录。
