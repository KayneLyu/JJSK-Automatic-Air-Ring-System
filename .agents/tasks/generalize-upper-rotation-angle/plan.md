## 阶段 2：统一扫描剖面预处理

- [x] 按实际扫描位置重采样到固定长度，而不是按采样序号对齐。
- [x] 正反扫描统一为空间上的同一方向。
- [x] 过滤无效值并将已知位置范围外保留为缺失，支持按比例对称裁剪边缘。
- [x] 完成默认关闭的去均值、线性去趋势和缺失值感知轻度平滑。
- [x] 输出输入有效率、位置覆盖率、重采样缺失率、方向和结构化拒绝原因。

验收项：

- [x] 同一剖面正序和反序输入得到等价结果。
- [x] 不同采样密度重采样后线性特征位置稳定。
- [x] 覆盖不足或有效点不足的扫描被明确拒绝。
- [x] 预处理默认值不改变原始重采样结果，非法选项被明确拒绝。

## 阶段 3：实现可靠的特征追踪

- [x] 将当前互相关升级为独立的逐位移零均值归一化互相关（ZNCC）候选核心。
- [x] 根据双方有限值的实际重叠区单独归一化每个位移候选。
- [x] 实现互相关主峰的三点抛物线亚像素插值，边界或退化峰保持整数位移。
- [x] 根据设备允许角速度、扫描时间间隔和角度采样分辨率动态限制搜索窗口。
- [x] 输出主峰、次峰、峰值突出度、相关度、置信度证据向量和结构化拒绝原因。
- [ ] 检测周期性、多峰和 `180°` 等价造成的歧义；数值等价多峰与边界峰已拒绝，近等价峰已量化但待独立统计判据。

验收项：

- [ ] 模拟平移的中位角度误差达到约定目标。
- [x] 对随机噪声、幅值缩放、偏置和部分缺失的性质测试保持稳定，并输出随质量退化变化的证据。
- [ ] 模糊峰不会被静默接受。

## 阶段 4：估计角速度并稳健过滤

- [x] 使用真实扫描时间戳计算 `ωᵢ = Δθᵢ / Δtᵢ`。
- [x] 用换向信号提供期望方向并检查符号冲突，保留原始有符号速度和绝对速度。
- [x] 排除换向附近、时间间隔异常和低置信度观测；端部时间与置信度门限均由调用方显式提供，生产参数值仍待物理或独立统计依据。
- [x] 使用无经验权重的中位数聚合匀速角速度。
- [x] 使用 MAD 检测离群值和速度不稳定性；输出 MAD、相对 MAD 与最大偏差，并由调用方显式提供相对/绝对容差执行拒绝，生产容差值仍待物理依据。
- [x] 由调用方显式定义每个完整行程所需的最少有效观测数。

验收项：

- [x] 分布性质测试确认单次极端错误不会显著改变最终匀速角速度。
- [x] 正向和反向匀速角速度绝对值按调用方显式设备容差执行一致性检查；生产容差值仍待独立确认。
- [x] 速度波动超过调用方显式设备容差时拒绝该行程；生产容差配置仍待独立确认。

## 阶段 5：建立短端部加减速模型

- [x] 换向点附近的数据不参与匀速特征估计；由阶段 4 的显式稳态时间窗筛选保证。
- [x] 第一版采用线性加减速端部补偿。
- [x] 使用 `θmax = ωconst × (Thalf - (Tacc + Tdec) / 2)` 计算行程候选。
- [ ] 端部时间优先来自设备配置或实测，当前无法获取时使用有明确边界的机台配置。
- [x] 对端部时间执行解析敏感性分析，输出每毫秒灵敏度、两端独立影响和联合角度区间。

验收项：

- [x] 补偿核心不包含历史端部时间默认值，不通过历史标签误差选择 12000/13000/20000ms 等动作。
- [ ] 已可精确量化端部参数小幅变化的角度影响；是否不可接受仍待设备角度容差确认。
- [x] 所有端部时间、匀速区存在性和角度范围均有边界校验。

## 阶段 6：多行程最大角度候选

- [x] 由连续稳定样本去抖后的互斥正反转信号划分完整行程；仅保留两个已确认换向边界之间的片段。
- [x] 每个行程输出最大角度、匀速角速度、有效观测数、速度离散度和逐维稳健汇总的置信度证据向量。
- [x] 聚合层强制至少联合一个正向和一个反向已接受行程；完整性仍由上游行程构建保证。
- [x] 多行程使用中位数聚合，并以调用方显式容差检测 Theil–Sen 稳健趋势漂移。
- [x] 行程时长、换向顺序或方向异常时拒绝候选；分段层校验边界与顺序，候选层再次校验行程和速度方向一致性。

验收项：

- [ ] 正反向角度差和跨行程标准差满足设备验收要求。
- [ ] 不完整或异常行程不会进入最终估计。

## 阶段 7：通用目标函数局部精调

- [x] 使用 Stage 6 多行程特征/速度积分候选的中位角度作为 `θfeature` 粗估，并通过只读适配层连接动态局部窗口。
- [x] 根据显式粗估不确定度分量的最坏情况总和动态生成局部搜索半径，并受全局边界与搜索点预算约束。
- [x] 仅保留通用 `evaluateExpanded`、局部搜索、黄金分割和边界保护；已通过只读适配器连接通用精调管线，尚未接入默认生产路径。
- [x] 比较特征粗估和局部通用目标函数结果；偏移超过调用方显式容差时拒绝，两者均不作为兜底。
- [x] 单一离线编排结果已输出最终角度、最终 loss、总不确定度、特征/目标偏移、证据来源及逐行程置信诊断。

验收项：

- [x] 新路径不依赖 DS 编号、固定目标角度带或样本融合系数。
- [x] 局部与全局边界均有显式保护，边界最优不会作为成功结果。
- [x] 双估计器冲突不会被任一分支无条件覆盖。

## 阶段 8：影子运行与独立验收

- [ ] 已具备当前生产、generic 基线和新混合路径的可序列化影子记录与批量统计核心；尚未接入实际采集/持久化调用点。
- [ ] 已具备机台/配方覆盖门禁，以及旋转速度、生产选中角度、膜宽的显式连续分桶统计；实际跨工况数据仍待采集。
- [ ] 至少收集 30 个完整标定窗口。
- [ ] 在冻结验收集上一次性计算最终指标。
- [ ] 检查最坏误差、严重错误和拒绝原因，而不只看平均误差。

建议初始验收目标，最终需结合设备精度确认：

- [ ] 最大角度中位绝对误差 `≤ 2°`。
- [ ] 95% 分位绝对误差 `≤ 5°`。
- [ ] 正反向估计差 `≤ 3°`。
- [ ] 同工况连续行程标准差 `≤ 2°`。
- [ ] 冻结验收集不存在大于 `10°` 的错误接受。
- [ ] 低置信度数据被拒绝，而不是输出伪精确结果。
- [ ] 单次估算保持小于 100ms。

## 每轮实施流程

1. 读取本任务 `context.md`、`plan.md`、`progress.md` 和 `decisions.md`。
2. 用 3～5 条总结当前状态。
3. 每轮只实施一个最小高收益动作。
4. 主动运行与风险相称的最小相关测试集，阶段验收运行对应测试矩阵。
5. 只追加更新 `progress.md`；重要取舍写入 `decisions.md`。
6. 若阶段验收失败，停止推进并记录原因，不通过新增样本定向规则掩盖问题。
