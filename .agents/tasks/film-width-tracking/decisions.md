# Decisions: 膜宽追踪与测厚仪运动控制

## 2026-07-02 20:51 方案选择

**背景**: 需将 Simulation 中已有的测厚仪运动模型（出膜宽后减速掉头）同步到实际设备控制中，同时解决膜外无效行程问题。

**选择**: 采用“混合策略 D”——先将 `thickness.mock.ts` 运动模型抽象为通用 `ScannerMotionController`，以标定膜宽为输入实现主动控制，同时预留自适应膜宽追踪接口。

**理由**:
1. 通用模型可保证 Simulation 与实际设备行为一致，便于调试
2. 标定膜宽为当前最可靠的膜宽来源，可立即落地
3. 预留自适应接口，后续可接入基于 `ProbeValue` 的膜宽自追踪，不阻塞长期演进

**影响**:
- 新增 `packages/AirRingServer/algorithms/scannerMotion.ts` 成为 Simulation 与 AirRingServer 的共享依赖

## 2026-07-02 21:30 否决标定膜宽方案

**背景**: 用户指出标定膜宽需要测厚仪先跑 10 趟才能标定，而运动控制又需要膜宽，形成死锁。

**选择**: 彻底放弃标定膜宽作为控制前置条件，改为基于 `ProbeValue` 在线检测的替代方案。

**理由**: "先运动才能标定，先标定才能控制运动" 不可调和，方案 A/D 从源头上不可行。

**影响**:
- 方案 D 中 `ScannerMotionController` 的膜宽源从"标定膜宽"改为"在线检测动态边界"
- Simulation 重构仍需与通用模型对齐，但模型输入参数不再依赖标定膜宽

## 2026-07-02 21:30 采用滑动单峰跳变+厚度为0双重判定

**背景**: 用户提出基于双峰算法派生"滑动单峰跳变检测"检测测厚仪是否出膜。

**选择**: 采用"方案 E"——双重判定策略：
- 优先级1（硬判定）：`calcThickness === 0` 连续≥3点 → 确认出膜（物理铁律，绝对可靠）
- 优先级2（软判定）：滑动窗口 AD 中位数跳变 → 辅助预警（统计鲁棒，抗噪声）

**理由**:
1. 膜内/膜外 AD 值物理差异达 10000+（从 `calcThickness` 和 `detectBimodalThreshold` 确认），信噪比极高
2. 硬判定基于物理定律（`ProbeValue ≥ airAD` → 无薄膜 → 厚度=0），零误报
3. 软判定利用统计分布，在 AD 跳变但尚未达 airAD 的过渡区提供预警
4. 不需任何标定参数，完全自适应

**影响**:
- 出膜检测完全不依赖标定膜宽，消除了原方案 D 的死锁
- 新增 `outOfBoundsDetector.ts` 替代原计划的 `scannerMotion.ts`

## 2026-07-02 21:45 三个实施约束

**背景**: 用户指定三个具体约束。

**选择**:
1. 优先判断膜厚度为0 —— 硬判定优先级高于软判定
2. 1秒出膜容错空间 —— 检测到出膜后等1秒再减速，1秒内回膜则取消
3. 同时标记左右两边出界的 `HorizontalPulse` —— 按 `MotionDirection` 区分左/右边界，记录脉冲值

**理由**:
1. 优先硬判定因物理可靠性最高，软判定仅作为备份
2. 1秒容错避免短暂出膜（噪声/边界模糊）误触发减速，减少设备磨损
3. 出界脉冲记录可用于后续膜宽推算（脉冲差 × 单位位移）和与限位脉冲对标

**影响**:
- 状态机增加 `TOLERATING` 状态 + `BoundaryPulseMap`（左/右出界脉冲记录）
- 出膜检测算法需额外输入 `HorizontalPulse` 和 `MotionDirection`

## 2026-07-02 22:00 方案评审与优化

**背景**: 对方案 E 进行完整性评审，发现4个P0、4个P1、3个P2级别问题。

**决定（P0）**:
1. **去掉软判定**：膜内/膜外 AD 差异为数量级，硬判定（厚度=0连续3点）已足够可靠；额外滑动窗口跳变检测增加代码复杂度但不参与实际控制，简化为纯硬判定
2. **对称回退**：TOLERATING→IN_MEMBRANE 回退改为连续3点厚度>0（与进入条件对称），避免单点噪声导致膜边缘震荡
3. **STOP→REV 安全间隙**：DECELERATING 必须确认脉冲停止 ≥200ms 才转 TURNING 发 REV，防止电机在运动中换向
4. **超时保护**：DECELERATING 5秒超时 + TURNING 3秒超时 → 告警，防止 PLC 无响应时状态机永久卡死

**决定（P1）**:
5. **增加 UNKNOWN 初始状态**：处理冷启动时探头在膜外的场景
6. **增加 EMERGENCY_STOP 状态**：任意状态下 `LeftLimit`/`RightLimit` 触发 → 紧急停止，禁止一切主动控制，需手动复位
7. **TURNING 方向验证**：发送 REV 后检查脉冲是否沿预期方向运动，N秒未验证 → 重发REV+告警
8. **状态转换日志**：每次状态转换输出结构化日志（时间戳+状态+原因+pulse+厚度）

**决定（P2）**:
9. 补充9个测试用例覆盖所有状态路径
10. Simulation ProbeValue 改造前做影响面分析（确认对 extractScanSegments/findMutation/Tracker 无破坏性影响）
11. 出界 pulse 推算膜宽反馈给 thicknessReversal 列为后续优化

**影响**:
- 状态机从4状态扩展到6状态（UNKNOWN / IN_MEMBRANE / TOLERATING / DECELERATING / TURNING / EMERGENCY_STOP）
- `outOfBoundsDetector.ts` 简化：去掉软判定，增加 `confirmedInMembrane` 输出（支持对称回退）

## 2026-07-02 23:00 容错窗口参数化

**背景**: 计算发现 1 秒容错窗口贡献约 67mm 无效行程（占单侧膜外行程 75%），远大于仿真模型的 26.7mm 理想值。

**选择**: 将容错窗口从固定 1000ms 改为**可配置参数**（默认 200ms），构建阶段在 `ScannerStateMachine` 构造函数中注入 `toleranceMs`。

| 容错窗口 | 单侧膜外行程 | 说明 |
|---------|------------|------|
| 200ms（推荐默认） | ~36mm | 3点硬判定 + 额外容错，双重保护 |
| 100ms | ~30mm | 接近仿真理想值（26.7mm），余量较小 |
| 0ms | ~23mm | 仅依赖连续3点，无额外容错 |

**理由**:
1. 3 点硬判定（90ms）已提供基本噪声保护，200ms 额外窗口使误触发概率极低
2. 200ms 默认值将膜外行程从 ~90mm 降至 ~36mm，与仿真模型（26.7mm）差距可控
3. 保留可配置性：实际部署后若膜边缘噪声大，可调大参数

**影响**:
- 状态机参数 `toleranceMs` 默认值: 1000 → 200
- 所有状态转换日志中 `toleranceMs` 输出实际配置值
- 后续可根据实际设备运行数据优化参数
