## Worker 边界

| 100,000 点载荷        |   中位数 |      P95 |
| --------------------- | -------: | -------: |
| JS 对象数组结构化克隆 | 82.435ms | 83.179ms |
| TypedArray transfer   | 17.501ms | 18.221ms |

该指标包含载荷构建、一次性 Worker 创建、发送和确认，符合当前 run-once Worker 模式的端到端比较口径。Rust PoC 应采用 TypedArray 批量 DTO，并单独报告 DTO 构建、边界和核心计算成本。

## 已知门槛

- DS02 的现有 TypeScript 生产结果为约 309.748°，相对标称 320.2° 偏差 10.452°；既有回归测试同步失败。
- AirRingServer 全量 typecheck 当前被仓库既有错误阻断，包括 `fft-js` 类型缺失、旧 import assertion、`confirmCount` 类型不一致和归档算法路径错误。
