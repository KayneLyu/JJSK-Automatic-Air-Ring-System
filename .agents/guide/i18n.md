# i18n.md — 国际化规则

## 项目国际化需求判断

- ✅ 项目使用 `vue-i18n`（`package.json` 依赖） 
- ✅ 存在 `locale/locales` 目录
- ✅ 有 `t()` / `$t()` 翻译函数调用

**结论：项目有国际化需求，涉及用户可见文案时必须严格遵守以下规则。**

## 强制规则（涉及 UI 文案时）

1. **禁止硬编码中文文案**：所有用户可见的文案必须使用 `t('key')` 或 `$t('key')`
2. **禁止 fallback**：不要在 `t()` 调用中直接写中文作为 fallback 参数
3. **Key 命名规范**：使用 `<feature>.<context>.<description>` 点分格式
   - 好：`upperRotation.settings.maxAngle`
   - 差：`maxAngle`、`上旋最大角度`
4. **新增语言 key 后**：必须同时更新 `zh-CN.json` 和 `en-US.json`

## 不受影响的区域

以下场景无需国际化：
- 日志输出（`console.log`、`console.warn`、`console.debug`）
- 代码注释
- 测试描述
- 错误信息（Node.js 后端抛出的 Error）
