# Task 目录标准模板

## context.md

```markdown
# Task: [任务名称]

## 背景
[描述任务产生的原因和动机]

## 涉及文件
[列出相关的源文件和目录]

## 约束
[列出技术约束、性能要求、兼容性要求等]

## 相关测试
[列出需要运行和通过的测试命令]

## 相关决策
[链接到 decisions.md 中的相关条目]
```

## plan.md

```markdown
# Plan: [任务名称]

## 先写计划再动手

### 步骤
1. [ ] [步骤 1 描述]
2. [ ] [步骤 2 描述]
3. [ ] [步骤 3 描述]

### 验收标准
- [ ] [标准 1]
- [ ] [标准 2]

### 预期产出
[描述完成后应交付什么]
```

## progress.md

```markdown
# Progress: [任务名称]

## YYYY-MM-DD HH:mm
[记录做了什么，结果如何]
```

> 只追加不修改，时间精确到分钟。

## decisions.md

```markdown
# Decisions: [任务名称]

## YYYY-MM-DD HH:mm [决策标题]
**背景**: [为什么需要这个决策]
**选择**: [选择了什么方案]
**理由**: [为什么选这个方案]
**影响**: [这个决策对后续的影响]
```

> 时间精确到分钟。

## 可选目录

- `scripts/` — task 内需要运行脚本时放在此目录
- `scripts/outputs/` — 脚本输出放在此目录
- 输出过长时立即转存到 files
